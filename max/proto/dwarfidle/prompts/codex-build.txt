RULES = IDEA 「규칙」 1~9 그대로: 원정대 5·층 B1~B10(무리 3 + 층 끝, B5·B10 대장)·자동 평타·필살기 게이지와 초상 탭 발동(명령 {k:'skill',who})·광석 하나·대장간 두 줄(명령 {k:'buy',item:'level'|'pick'})·밀기/사냥 모드와 도전(명령 {k:'challenge'})·실패 카드(전멸 event 에 대장 남은 체력 비율)·방치 복귀(명령 {k:'resume',seconds} — 그리는 쪽이 visibilitychange/pagehide·로드 때 저장 시각과 Date 로 경과초를 계산해 넣는다, 최대 8시간, 1분 미만 무시)와 상자 받기(명령 {k:'chest'})·B5 대장 승리 = 홀 복원(할인 20%)·B10 승리 = 큰 화로 점화. 게임 진행 상태도 저장 키 proto_dwarfidle_ 아래 localStorage 에 저장·복원(try/catch, ?check 에선 저장 안 함).
2. 화면 = ART.md §3 · mock-core.png 배치: 기록 띠 → 층 표시(ui-slot, "B3" + 무리 점 3개)·광석 칩(icon-copper + 숫자) → 요새 단면(hold-dark, 복원 뒤 hold-lit) → 전투 띠(battle-bg 를 잘라 씀, 원정대 왼쪽부터 요리사·등불지기·화약꾼·주인공·방패병, 적 오른쪽, 머리 위 작은 체력 막대, 피해 숫자) → 초상 5(ui-portrait 틀 + 머리 원형 자르기 + 필살기 고리, 차면 빛남·탭 가능) → 아래 단추: 대장간(ui-btn-gold, 열면 ui-panel 창에 레벨 줄·곡괭이 줄 + 비용, 살 수 있으면 단추 빛남) · 상자(ui-btn-stone, 쌓인 양) · 도전 B○(사냥 중에만). 오른쪽 깊이 막대(ui-rail, B1~B10 눈금, B5·B10 대장 표식, 지금 층 빛남, 맨 아래 forge-ruined 를 어둡게 → B10 승리 뒤 forge). 첫 실행에만 intro.jpg 시작 장면(위→아래 카메라 약 6초, 탭하면 넘김). 글자는 한국어 최소(층 이름·숫자·「강해져서 다시」·「대장간 홀 복원」·「큰 화로에 불이 붙었다」·단추 이름 정도), 모두 data strings 에.
3. 연출(SPEC 「캐릭터」 아래 글머리): 주인공 = 곡괭이 단계별 휘두르기 시트(공격마다 0→7 재생, 대기 0칸 + 숨쉬기)·걷기 시트·필살기 시트·반응 시트(맞기/쓰러짐/환호), 동료 = 정지 그림 + 공격 때 atk-* 그림으로 바꾸고 짧은 돌진(코드), 적 = 튀기·붉은 번쩍임·죽으면 납작해지며 광석 튐. 필살기마다 다른 이펙트(코드: 빛·입자·흔들림·화면 번쩍임). 무리 사이엔 원정대가 걷고 배경이 흐름. 받는 순간 연출(proto/AGENTS.md §4b): 대장 승리·홀 복원(hold-dark→hold-lit 금빛 번짐 + 입자 + 흔들림 + 효과음)·B10 화로 점화·상자 받기·레벨업. 소리는 SPEC 소리 표 대로 WebAudio 합성.
4. 코어 루프 기록(§4a): 바퀴 = 무리 하나(IDEA 「이벤트」). 의무 5분·자발 판수·?stats 유지.
5. 빠른 트랙이라 **가짜 BM·소셜 자리는 뺀다**(템플릿 bm/social 단추·광고 화면·이웃 지우고, 관련 검사도 지우지 말고 "BM·소셜 없음" 을 확인하는 검사로 바꿈). ?stats 의 BM·소셜 표도 뺀다.
6. 페이스 봇 T.bot(seconds): IDEA 「페이스 목표」 아래 「봇 행동」 그대로. 논리 명령만 쓰고(화면 입력·기록·저장 오염 없음, 끝나면 상태 복원 — 템플릿 봇 검사 유지), 지표 네 개(firstB5BossMin·b5FailToWinMin·b10WinMin·b5NoSkillWinRate)를 metrics 로 돌려준다. 못 닿은 지표는 null(= 실패). data pace 에 IDEA 표 min/max/why 를 옮긴다. check.cjs 「페이스」 검사는 B10 까지 닿게 T.bot(6000) 으로 돌린다 — 빠르게 돌도록 봇은 RULES.apply/tick 만 직접 부른다(렌더 없음). **수치(체력·공격·비용·광석량·게이지 속도)는 네 지표가 모두 범위 안에 들어올 때까지 조정**하고, 정한 핵심 수치를 data 블록 balance 에 둔다(RULES 는 data 에서 읽음).
